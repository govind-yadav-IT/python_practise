# Day 9 – Python Practice

**Objective:** Learn to write Python programs independently from a blank screen.

### Scripts to Develop

1. **hello.py**
   - User input using `input()`
   - Variables
   - Output using `print()`

2. **compare.py**
   - Accept two numbers.
   - Convert input using `int()`.
   - Compare numbers using `if`, `elif`, and `else`.
   - Display the bigger number or equal.

3. **evenodd.py**
   - Accept a number.
   - Use the modulus operator `%`.
   - Check whether the number is even or odd.

4. **count.py**
   - Use `for` loops.
   - Understand `range()`.
   - Print numbers from 1 to 10.
   - Calculate their sum.

5. **Error Drill**
   - Enter invalid input.
   - Understand Python error messages.
   - Identify and explain errors.

6. **Git and GitHub**
   - Create `python_practice` folder.
   - Add all five Python files.
   - Commit the files using Git.
   - Push the project to a new GitHub repository named `python-practice`.
   - Verify commits using `git log --oneline`.

**Expected Outcome:** Develop independent Python programming, logical thinking, debugging, and Git/GitHub skills required for DevOps engineering.
